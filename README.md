# xhand pro · Pen spinning

[Open the interactive demo](https://evan715823.github.io/xhand-pen-spin-demo/)

Chinese / English. Created by [YIfan Hu](https://evan715823.github.io/).

A selected 2.059-turn Isaac Lab recording. Independent evaluation: 4 / 4335 successes (0.0923%); experimental, not a stable two-turn policy. The controller combines PPO with fixed finger adjustments and stop-and-hold. The browser replays recorded states and does not run physics.
